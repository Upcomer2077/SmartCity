# Общие сведения
## Проект: SmartCity
Интеллектуальная платформа мониторинга городской инфраструктуры
### Цель разработки:
Создание веб-платформы, собирающей, обрабатывающей и визуализирующей данные от IoT-датчиков, установленных в городской инфраструктуре (транспорт, экология, температура, освещение и т. д.).
